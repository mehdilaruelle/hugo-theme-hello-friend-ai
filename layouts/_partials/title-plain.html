{{- /* A page's title as plain text, for everywhere but its own h1 and the Markdown outputs: the tab, the cards, JSON-LD, the lists, the feed. The h1 renders a title's inline Markdown, so `code` and *emphasis* elsewhere showed their backticks and asterisks. A title with no Markdown is returned as written. */ -}} {{- $title := partial "title.html" . -}} {{- $html := partial "title-inline.html" (dict "text" $title "with" "<") | markdownify -}} {{- if strings.Contains $html "<" -}} {{- $title = $html | plainify | htmlUnescape -}} {{- end -}} {{- return $title -}}
