{{- /* First picture out of an `images` key, whatever shape it was written in. Empty string when there is none. `index` on a Go string returns the byte at that offset, so images = "img/card.png" came out as 105. A string is read as a list of one. Any other shape warns rather than being indexed, like social-icons.html. Reached through `isset`, not `with`: `with` is false for 0 and for an empty table, which would skip the check. Hence the empty shapes are named here -- nil, "", [] and [""] (the README's sample) mean "no picture", and stay quiet. */ -}} {{- $first := "" -}} {{- $type := printf "%T" . -}} {{- if eq $type "" -}} {{- else if reflect.IsSlice . -}} {{- with index . 0 -}} {{- if eq (printf "%T" .) "string" -}} {{- $first = . -}} {{- else -}} {{- warnidf "images-shape" "images: expected a list of paths, got a list of %T. This page has no social card picture." . -}} {{- end -}} {{- end -}} {{- else if eq $type "string" -}} {{- $first = . -}} {{- else -}} {{- warnidf "images-shape" "images: expected a path or a list of paths, got %T. This page has no social card picture." . -}} {{- end -}} {{- return $first -}}
