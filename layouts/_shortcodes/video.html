{{- /* A video standing in for an animated GIF. Autoplays muted on a loop, like the GIF it replaces, so an article reads the same — but with the player controls a GIF never had, because a loop runs for as long as the page is open and a reader has to be able to stop it. controls="true" chooses the other mode: no autoplay and no loop, so the clip waits to be started. The controls are there either way. src is the path without an extension. Every source given in formats is emitted, in order, and the browser takes the first it can play; put the smaller encoding first. Width and height are worth passing: a video has no intrinsic size until it loads, and without them the page jumps. {{< video src="/demo/recording" poster="/demo/recording.jpg" width="1600" height="900" alt="A session being recorded" >}} */ -}} {{- $src := .Get "src" -}} {{- $formats := split (.Get "formats" | default "webm,mp4") "," -}} {{- $controls := eq (.Get "controls") "true" -}} {{- /* A site served from a subpath needs it kept; a remote URL must be left alone. */ -}} {{- $poster := "" -}} {{- with .Get "poster" }}{{ $poster = partial "abs-url.html" . }}{{ end -}} {{- if $src -}} {{- end -}}
