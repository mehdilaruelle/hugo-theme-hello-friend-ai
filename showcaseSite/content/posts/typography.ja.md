以下の要素はすべて、テーマが見た目を与えているものです。ここに集めてあるのは、
スタイルシートを変えたときに全部を一度に確かめられるページがあるようにするため
です。何か月も経ってから誰かのブログで気づく、ということにならないように。

## コード

サイトのビルド時に Chroma で色付けされ、言語はコードフェンスから取られます。

```go
func main() {
	sites := []string{"example", "showcase"}
	for i, s := range sites {
		fmt.Printf("%d: %s\n", i, s)
	}
}
```

文中の `code` は行の高さを崩さずに収まります。このテーマが以前、ふたつの
セレクタで同時に取りこぼしていた部分です。

## 表 {data-columns=3}

| オプション | 既定 | 何をするか |
| --- | --- | --- |
| `enableThumbnails` | 無効 | 一覧ページのカバー画像 |
| `defaultTheme` | 未設定 | OS の設定に従う |
| `direction` | `ltr` | 右から左に読む言語で配置を反転する |

## 引用

> テーマは箱から出したとき、機能一覧ではなくテーマ自身に見えるべきです。

## リスト

1. 順序のあるもの。順番に起きる手順のために
2. 二番目の項目があると、字下げが見えます
   - そして入れ子の順序なしリスト
   - 右から左に読む言語で左右の余白が現れるのはここです


## 数式

front matter の `math = true` は、このページにだけ KaTeX を読み込みます。行内は
\(a^2 + b^2 = c^2\)、独立した式はこちら。

$$
\int_0^\infty e^{-x}\,dx = 1
$$

本文から自動検出せず明示的にしてあるのは、シェルの断片では `$$` がただの文字で
あり、誤検出すると 300 KB を無駄に取りに行くからです。

## 画像

`image` ショートコード、中央寄せ:

{{< image src="img/example.png" alt="テーマのスクリーンショット" position="center" >}}

`position` は意図的に物理的なままです。`left` と指定することはページの左を指す
ことであり、それはどの言語でも変わりません。まわりの余白が反転するのとは別の
話です。
